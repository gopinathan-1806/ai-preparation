# How to Update These Notes

When a new Social Eagle class is completed:

1. Keep the raw classroom notes in their original wording.
2. Add the topic to the appropriate folder.
3. Add an **Additional Study Details** section for missing concepts, caveats, examples, and production considerations.
4. Add code snippets only after understanding what each line does.
5. Add an **Interview Questions** section when the topic becomes interview-relevant.
6. Add **My Project Usage** when the concept is used in a real project.
7. Do not delete old notes just because a newer explanation is better; preserve the learning history and clearly mark updated understanding.
